Auto backup and restore settings & bookmarks via a secret GitHub Gist with Personal Access Token.

Setup Guide: How to get Token
  1. Go to GitHub Token Settings.
  2. Ensure the gist checkbox is checked (only 'gist' permission is required).
  3. Click Generate token and copy your token (starting with ghp_).
  4. Paste token below, click Upload to create your private backup Gist.
Your token is stored only locally in your browser and connects directly to GitHub.

Create a token with 'gist' scope at github.com/settings/tokens.

Leave blank to create a new secret Gist on upload, or enter an existing Gist ID to connect.

Auto backup and restore settings & bookmarks via a private GitLab Snippet with Personal Access Token.

Setup Guide: How to get Token
  1. Go to GitLab Access Tokens.
  2. Enter a token name (e.g. Startpage Sync).
  3. In Scopes, check the api scope (required for Snippet API).
  4. Click Create personal access token and copy your token (starting with glpat-).
  5. Paste token below, click Upload to create your private Snippet backup.
Your token is stored only locally in your browser and connects directly to GitLab.

Create a Personal Access Token with 'api' scope at gitlab.com/-/user_settings/personal_access_tokens.

Leave blank to create a new private Snippet on upload, or enter an existing Snippet ID to connect.
