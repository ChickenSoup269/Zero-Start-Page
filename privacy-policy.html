Zero Bookmark Manager

The sole purpose of this extension is to provide users with an easy interface to manage bookmarks (view, organize, search, and edit).

1 01. Access & Permissions

Bookmarks

Required to access the user's bookmarks in order to display them, organize folders, search by title or URL, edit bookmark details, and detect and remove duplicate bookmarks automatically.

Local Storage

Used to save user preferences, such as the preferred quick-open behavior (popup, side panel, or web view), so the extension can remember and apply these settings across sessions.

Side Panel

Required to open the bookmark manager interface inside Chrome's side panel, allowing users to view and manage their bookmarks without leaving or interrupting the current browsing page.

Tabs Management

Used to detect whether the bookmark manager page is already open, activate and focus an existing tab if found, or create a new tab when necessary to prevent duplicate pages.

Identity

Required to authenticate users securely with their Google Account using OAuth2. It is exclusively used to obtain an access token to interact with the Google Drive API for backing up and syncing user settings. We do not use this permission to collect personal information.

System Display

Used to obtain screen and work area dimensions in order to correctly position the extension's popup window on the user's screen.

Web Navigation

Required to track user interactions with bookmarks. It allows the extension to monitor when users navigate to bookmarked URLs, ensuring accurate tracking of bookmark usage.

2 02. Data Usage

  • No Data Sharing: Zero Bookmark Manager does not collect, sell, or transfer user data to third parties.
  • Local Processing: Bookmark data is accessed only for the purpose of displaying, organizing, searching, editing, and removing duplicate bookmarks. All processing is performed locally.
  • Storage: User preferences and extension settings are stored locally using Chrome's storage API and remain on the user's device.
  • Chatbot: The chatbot is now a command-based system and does not utilize AI or third-party APIs. This ensures complete privacy and local processing.

3 03. Additional Info

  • Source Code: The extension is open-source. You can review the code and releases on GitHub (ChickenSoup269/Zero-Bookmark-Manager).
  • Known Issues: Minor UI refresh issues after moving items. Fix: Refresh page (F5).

Zero Startpage

To facilitate compliance with Chrome Web Store Developer Program Policies, the following declarations describe the extension's single purpose and permission usage.

1 Single Purpose Description

Overview: Startpage replaces Chrome's new tab page with a customizable personal dashboard. It provides local bookmark management, clock/calendar widgets, search shortcuts, optional background and visual effects, and optional media controls/visualization for active audio tabs. Its single purpose is to give users a personalized and productivity-focused new tab experience.

2 Permission Justification

Bookmarks

Used only when the user chooses to import bookmarks into Startpage. The extension reads the bookmark tree via Chrome Bookmarks API so users can select and import items into their local Startpage view. No data is sold or shared.

Scripting

Used to execute short in-page scripts in the currently detected media tab to read playback metadata and to perform user-requested media controls. Scripts are packaged with the extension and are not remotely loaded.

Tabs

Used to locate audible/media tabs and read tab URL/title context needed to identify supported media pages (e.g. YouTube) and show current playback information. Not used for advertising or profiling.

Storage

Required to synchronize user settings (theme, layouts) across different devices via chrome.storage.sync. It also tracks extension version updates and persists user-generated content like todo lists and notes.

Identity

Required to authenticate users securely with their Google Account using OAuth2. It is exclusively used to obtain an access token to interact with the Google Drive API for backing up and syncing user settings.

Host Permissions

Required for: requesting search suggestions from Google, reading media state/controls on supported sites, and supporting optional media detection. All access is feature-scoped and initiated by extension functionality.

3 Google API Services Usage Disclosure

Google Drive API: Zero Startpage uses Google Drive API to backup and sync your settings. The extension only creates, reads, and modifies files created by the extension itself in your Google Drive. We do not have access to your personal files, and we do not store, share, or transmit your Google Drive data to any third-party servers. Your data stays between your browser and your Google account.
